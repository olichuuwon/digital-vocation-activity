# Playtest notes (M8)

Goal (spec §12): 5+ players aged 12–25. Median run **14–17 min** (replays with bonus levels are extra and untimed for this goal).
Fill in one block per session. Claude reads this file to rebalance (`/balance`).

## How to run a session
- Use the live site on the player's own phone (or a booth phone). Don't explain the game: just say "This is a game about building a disaster-relief app. Go!"
- Note the time when they tap **Play** and when the debrief appears. Optional: write down when each stage starts.
- Watch, don't help. If they're stuck for more than 30 seconds, note it, then help.
- Teams: also watch the teammates on the Waiting screen. Are they looking at the player's phone and talking?

## Checklist (spec §13)
- Did they smile or say "one more go" at least once per stage?
- Where did they hesitate for more than 5 seconds without acting? (Fix the UI or copy there.)
- Can they explain in their own words what one of the four roles does? (Ask after the debrief.)
- Did anyone get stuck without a way forward? (Must be zero.)
- Team mode: did the watching players talk at least every ~20 s? Did anyone tune out for a whole stage? (Must be zero.)
